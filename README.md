Entry for the [make.fun bounty "One-Star Review of Something Essential"](https://make.fun/bounty/u-0xb3e689-one-star-review-of-something-essential-c7234629).

## What it does

`main.py` writes one single-line, deadpan one-star review of sleep — an everyday
essential — to `/output/entry.txt`. The review is 95 characters, well inside the
160-character gate, and is written deterministically with no network access and
no dependencies beyond the Python standard library.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
